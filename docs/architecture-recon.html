Architecture recon · 2026-07-23

One deep seam replaces duplicated game logic.

Original pressure points

  1. Global state, rendering, prompts, and rules share one inline script.
  2. Keyboard and button movement implement competing versions of the same rules.
  3. Win conditions disagree, and browser dialogs interrupt the game loop.

Chosen architecture

Keyboard · touch · swipe→ GameSession
pure deterministic rules→ Canvas · HUD · audio · storage

The seam sits between player intent and resulting state. The same action drives every input mode, while presentation remains replaceable and testable.

Boundaries

  • game-session.js: generation, movement, encounters, outcomes.
  • canvas-renderer.js: visual projection only.
  • main.js: browser events and state orchestration.
  • audio.js and storage.js: optional browser capabilities.
