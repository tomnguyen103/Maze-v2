# 0029: Lock one Learning Deck revision to each Quest

- Status: Accepted
- Date: 2026-07-29

A Quest chooses one immutable Learning Deck revision at creation and cannot
switch it before that Quest ends or is replaced. Quest Level owns Question
complexity and Labyrinth challenge; Learning Deck owns the preferred reviewed
learning-objective mix. Because wrong answers, Question Skips, defeats, and
retries create unbounded Question demand, focused-content exhaustion never
blocks play, repeats a used Question, or generates unreviewed content. The game
announces one fallback to unused Mixed Trail Questions at the same Quest Level
and Difficulty Band while retaining the selected Deck identity. This accepts
imperfect Deck purity so Quest-wide uniqueness, legitimate retries, cloud
continuity, and child-safe reviewed content remain intact.

The launch roster is exactly Mixed Trail, Number Trail, Word Trail, and Nature
Trail. A non-Mixed Deck revision cannot publish unless, at every Quest Level,
it supplies focused reviewed Questions for at least 70% of correct-first Warden
encounters in each of the five Regions and a Deck-matched Capstone Question for
each Region's Gate Warden. Mixed fallback covers legal demand beyond that
published focus boundary.
