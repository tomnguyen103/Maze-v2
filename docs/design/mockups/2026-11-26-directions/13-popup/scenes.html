Echo Atlas as a pop-up book

The proposal: the Echo Atlas is a book the Explorer carries. The left page is a stamp sheet, one perforated stamp per Labyrinth and one row per land. The right page is the open land as a tunnel book: four cut-paper layers, one per Labyrinth, with the Gate Warden at the back. Index tabs on the edge turn to each land.

Start a Quest

The Quest setup has three steps, as today. Each step is a page with pull-tab choices. Plain words, large targets, one choice per page.

Play

The board is a page in the book. The Readout hangs from the top edge as ribbon bookmarks. Controls are pull-tabs along the bottom edge. Fog flaps all look the same, so they never give away the route.

Warden Challenge

The Question card pops up from the board like a page in a book. Every card has Read Aloud, a free Hint, and Question Skip. Harder Quest Levels add steps and reasons. They never add smaller text or a darker look.

How the Atlas works

Each part of the Atlas is a real paper mechanism, so it can be built from paper, scissors, and glue.

Tunnel bookCut layers stand one behind the other. Each layer is one Labyrinth, so the land reads front to back, and the Gate Warden waits at the back.
Stamp sheetTwenty perforated stamps show the whole Quest on one page. A postmark means cleared. A child counts progress without a scroll.
Index tabsTabs on the page edge turn to a land, like a real atlas. Each tab says how many Labyrinths are cleared.
Sigil sealsA wax-style seal closes each stamp row. It fills in when the Gate Warden of that land falls.
One actionThe bar under the book has one main pull-tab: Play Labyrinth 7.
Left outPan, zoom, and a large canvas. The whole Quest fits on one spread.
