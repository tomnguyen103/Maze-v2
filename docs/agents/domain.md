# Domain docs

This repository uses a single-context domain model.

Before changing game rules:

- Read `CONTEXT.md`.
- Read relevant decisions under `docs/adr/` when that directory exists.
- Use the glossary's canonical terms in issues, tests, and code.
- Surface conflicts with an ADR instead of silently overriding it.

Create domain files lazily. `CONTEXT.md` is a glossary, not a specification or implementation log.
